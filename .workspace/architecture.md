## 目录结构

```

├── src/              # 源代码
│   ├── components/   # 组件
│   ├── hooks/        # 自定义 Hooks
│   ├── utils/        # 工具函数
│   ├── services/     # API 服务层
│   ├── stores/       # 状态管理
│   └── types/        # 类型定义
├── tests/            # 测试文件
│   ├── unit/         # 单元测试
│   └── e2e/          # E2E 测试
├── docs/             # 文档

│   └── memory/       # 持久知识
└── public/           # 静态资源
```
